# AutoBudget

> **Веб-версия онлайн: https://ddk79j5z5r-dotcom.github.io/AutoBadget/** · исходники в папке [`web/`](web/README.md) — React + TypeScript, данные в браузере.

Учёт расходов на автомобиль. SwiftUI · MVVM · SwiftData · Swift Charts · NavigationStack. iOS 17+.

## Запуск

Откройте `AutoBudget.xcodeproj` в Xcode → выберите симулятор → ⌘R.
При первом запуске загружаются демо-данные: Toyota Aristo JZS160, 1998, 2JZ-GE, 430 000 км.

Проект сгенерирован из `project.yml` через XcodeGen. После добавления файлов:

```bash
xcodegen generate
```

Иконку и иллюстрацию автомобиля можно перегенерировать скриптом:

```bash
swift Tools/GenerateIcon.swift
```

## Как устроено

- Детали добавляются в записи ремонта («Заменённые детали»). Ресурс считается от пробега и даты установки;
  статусы: «В норме» → «Скоро» (< 5 000 км / 30 дней) → «Срочно» (< 1 000 км / 7 дней) → «Требуется замена».
- Новая деталь с тем же названием и категорией автоматически снимает с учёта предыдущую — так строится история замен.
- Напоминания — для процедур и документов (ОСАГО, техосмотр), детали — для узлов. На главной оба источника
  сведены в один список, отсортированный по среднесуточному пробегу.

- Каждый ремонт автоматически создаёт связанный расход в бюджете (категория «Ремонт» или «Обслуживание» для ТО). Изменение или удаление ремонта обновляет и расход.
- Пробег автомобиля увеличивается сам, если в новой записи он больше текущего.
- Напоминания считают срок по пробегу и/или по времени. Уведомление приходит за N дней до даты (в 10:00), а при превышении пробега — сразу.
- Средний расход топлива считается методом полного бака по заправкам с указанными литрами.
